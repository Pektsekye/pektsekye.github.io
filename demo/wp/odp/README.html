Date Price Calendar 1.0.0  


This plugin uses a Text Field product option to display a popup calendar for WooCommerce products.
So customer can select date as product option before adding the product to the shopping cart.
The store administrator can specify available date ranges on the edit product page.
He can set price for each date range or a single day and make the option required "mandatory" for selection.
So the customer will not be able to add the product the shopping cart without selecting a date.
The selected date is saved as product option. So it is displayed on the checkout pages and in the order complete emails.

An example of how to use it

 1) Open any Simple product in: Wordpress admin panel -> Products (screenshot)
2) In the Custom Options section click the Add Option button to add a new option. (screenshot)
   Note: if there is no "Custom Options" section you should install and enable the Product Options plugin.
3) Set option title "Choose Date" and select option type Field. (screenshot)
4) In the Calendar Option section select your "Choose Date" text field option. (screenshot)
   Note: if there is no "Calendar Option" section it means that this plugin was not successfully installed and enabled. Check the Troubleshooting instructions in this readme file.
5) Click the Add Range button to add new date ranges. (screenshot)
6) Set dates and price for your ranges. (screenshot)
7) Click the Update button to save the product. (screenshot)
8) Check the result on front-end product view page. The calendar popup should appear if you click on the "Choose Date" text field option. (screenshot)
Only the specified date ranges should be available for selection. And if you select a date product price should change.
If it does not work this way check the Troubleshooting section in this readme file.

Troubleshooting
  • If this plugin does not work

    • Try to disable other plugins.

    Try to use the default WooCommerce theme "Storefront".

    Check if the browser error console has any error messages.

    Check if the page HTML source has any error messages.

    Try to enable WordPress debug logging by setting:
    define( 'WP_DEBUG', true );
    define( 'WP_DEBUG_LOG', true );

    in the wp-config.php file.

    and then check if the log file:
    wp-content/debug.log

    contains any errors.
