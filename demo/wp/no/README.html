Notify Odoo 1.0.0


This plugin sends a notification to the Odoo website when a new order is created on the WooCommerce website.
In two minutes the Odoo website sends a request to the WooCommerce website to get the new order data and then saves it as a new order on the Odoo website.

Installation


Requires WordPress 4.7 or later, WooCommerce 3.5 or later, Odoo 12 or later

1) Unzip the downloaded zip file.
2) Upload the plugin folder into the `wp-content/plugins/` directory of your WordPress site.
3) Activate `Notify Odoo` from the Plugins page.

An example of how to use it

1) Go to WordPress dashboard -> WooCommerce -> Settings -> Advanced -> REST API
And click the Add Key button. (screenshot)
2) Generate a key with read/write permissions. (screenshot)
3) Copy the secret keys and save them in some temporary file on your computer. (screenshot)
4) On the Oddo website install the "Enotif WooCommerce Order" module. It will appear as "External Notifications" application because it is part of this app. (screenshot)
You can download the "Enotif WooCommerce Order" module on this page:
https://apps.odoo.com/apps/modules/19.0/enotif_woo_order/
5) On the Oddo website go to Odoo admin panel -> External Notifications -> WooCommerce Keys
And specify your WooCommerce URL and the secret keys. (screenshot)
6) On the same page click the "Check Connection" button to save the fields and verify the connection to your WooCommerce website. (screenshot)
If there is a connection error it is possible that your WooCommerce website blocks requests from bots, scripts. You should ask your hosting support about it.
7) On the WooCommerce website go to WordPress dashboard -> Notify Odoo
And specify URL of your Odoo website. (screenshot)
8) Click the "Check Connection" button to verify connection from WooCommerce to Odoo (screenshot)
If there is a connection error and the Odoo server is installed on a local computer check if your Odoo server is accessible to the web.
9) If the connection is good then try to create a new order (buy something as a customer) on the WooComerce website. (screenshot)
10) Wait for two minutes. Then go to Odoo admin panel -> Website -> Orders
And check if your new order has been copied from WooCommerce to Odoo (screenshot)
