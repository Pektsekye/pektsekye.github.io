Product Options 1.0.0  Mar 2 2021


This plugin adds selectable options to WooCommerce products.
So customer can select size, color and specify custom text before adding a product into the shopping cart.
The store administrator can create product options on the edit product page.
He can set price for each option value and make options required "mandatory" for selection.
So the customer will not be able to add the product the shopping cart without selecting the required options.

Installation

 1) Wordpress admin panel -> Plugins -> Add New
Click the "Upload Plugin" button (screenshot)
Select the product-options-for-woocommerce.zip file and click the "Install Now" button (screenshot)

Also you can install it manually.
Unzip the product-options-for-woocommerce.zip archive and upload 19 new files into "wp-content/plugins" directory of WordPress:

An example of how to use it

 1) Open any Simple product in: Wordpress admin panel -> Products (screenshot)
2) Open the Custom Option section. (screenshot)
3) Click the Add Option button to add a new option. (screenshot)
4) Select option type Drop-down. (screenshot)
5) Click the Add New Row button to add a new option value. (screenshot)
6) Fill the option title and option value titles fields. (screenshot)
7) Click the Update button to save the product. (screenshot)
8) Check the result on front-end product view page. (screenshot)

Limitations

 The current version of this extension supports only Simple products:
(screenshot)

Also it uses JavaScript to change product price so it is very dependent on theme's HTML

If this plugin cannot find and update the price on the frontend product view page when you select a product option you should adjust the line:
    this.priceDiv = $('#product-'+ this.productId +' .summary .woocommerce-Price-amount');

in the file:
wp-content/plugins/product-options-for-woocommerce/view/frontend/web/product/main.js

Troubleshooting
  • If the product price is not updated when a product option is selected on front-end:

    • Adjust CSS selector:
    this.priceDiv = $('#product-'+ this.productId +' .summary .woocommerce-Price-amount');

    in the file:
    wp-content/plugins/product-options-for-woocommerce/view/frontend/web/product/main.js

  • If this plugin does not work

    • Try to disable other plugins.

    Try to use the default WooCommerce theme "Storefront".
    https://wordpress.org/themes/storefront/

    Check if the browser error console has any error messages.

    Check if the page HTML source has any error messages.

    Try to enable WordPress debug logging by setting:
    define( 'WP_DEBUG', true );
    define( 'WP_DEBUG_LOG', true );

    in the wp-config.php file.

    and then check if the log file:
    wp-content/debug.log

    contains any errors.
