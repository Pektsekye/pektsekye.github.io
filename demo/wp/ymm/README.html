Year Make Model Search 1.0.12  


With this plugin store visitor can search for a product (usually a replacement part) that applies to specific vehicle.
For example if the product is a car bulb the visitor can select car make and model in the YMM selectors box.
Then he will be redirected to the search results page where all matching products will be listed.

Display it with a shortcode

 You can insert the YMM search box into the page content with this shortcode:

  [ymm_selector template="horizontal_selector.php"]


(screenshot)

Or with a Shortcode block (if your theme supports blocks):
(screenshot 2)

Result on the front-end: (screenshot)


Shortcode parameters:

If you need a horizontal selector box:
[ymm_selector template="horizontal_selector.php"]

To enable the "garage" feature:
[ymm_selector garage=1]

To enable the "remove from garage" link:
[ymm_selector remove_from_garage_enabled=1]

To disable the "filter category page" mode:
[ymm_selector filter_category_page=0]


Also you can insert it in a PHP template file as:

<?php echo do_shortcode('[ymm_selector template="horizontal_selector.php"]'); ?>

Product Restriction Format

 Restriction means what a user selects on front-end.
If the user selects "Acura Legend SE 1995" then all products with restriction "Acura, Legend SE, 1995, 1994" will be found.

Restriction can not be lower case like:
acura legend se 1995

because this extension displays restriction values as drop-down options on fron-end.

Year From and Year To values should always have four digits like 1999

Commas in the restriction is mandatory. Each new restriction phrase should go on a new line the same as in a .csv file.
All values are optional.
So instead of complete restriction "Acura, Legend SE, 1995, 1996" it is possible to use:

Acura, Legend SE,,

or:
Acura,,1995,

or:
Acura,,,

The restriction "Acura,,," means that the product will be displayed for all models and years of the Acura make.
The restriction "Acura, Legend SE,," means that the product will be displayed for all years of the Acura Legend SE.

The restriction "Acura, Legend SE, 1992, 1995" means that the product will be displayed for "Acura Legend SE" with any of the years: 1992, 1993, 1994, 1995.

It is possible to use restriction with empty values (just three commas) like ",,," to make a product "universal"
This product will be displayed for any make and model selected.

One product can have multiple restrictions but each should be on a new line:

Jeep,,,
Ford,,,
Acura, CL, 2003, 2005
Acura, Integra GS,,
Acura, Legend Base, 1986, 1992
Honda, Civic LX,,
Honda, CR-V EX, 1999,,
Honda, Odyssey Cargo, 1999, 2002
Honda, Passport EX,,
Toyota, Celica GT, 1992, 1995

Translate

 1) Open the .pot template file:
wp-content/plugins/ymm-search/i18n/languages/ymm-search.pot

with some text editing program.

2) Translate strings in it. Example:
msgid "(What is an API key?)"
msgstr "(Ce este o cheie API?)"
3) Save translated file as .po file on your computer.

4) Convert the .po file into a .mo file with some program like PoEdit, Loco Translate plugin or online service (google for "convert .po to .mo").

5) Save the .mo file as ymm-search-YOURLOCALECODE.mo into the ymm-search/i18n/languages directory.
Example for Romaninan language:
wp-content/plugins/ymm-search/i18n/languages/ymm-search-ro_RO.mo

6) Enable your language in WordPress dashboard:
Dashboard > Settings > General
(screenshot)


If your translation is ready you can share it with other WordPress users on translate.wordpress.org
When you translation is approved on translate.wordpress.org the files will be automatically downloaded into wp-content/languages/plugins directory when WordPress language is changed.
Example of auto-downloaded files for Romanian language:
wp-content/languages/plugins/ymm-search-ro_RO.mo
wp-content/languages/plugins/ymm-search-ro_RO.po
The translations from the plugin directory:
wp-content/plugins/ymm-search/i18n/languages/ymm-search-ro_RO.mo
override the auto-downloaded translations.

Troubleshooting
  • If this plugin does not work

    • Try to disable other plugins.

    Try to use the default WooCommerce theme "Storefront".

    Check if the browser error console has any error messages.

    Check if the page HTML source has any error messages.

    Try to enable WordPress debug logging by setting:
    define( 'WP_DEBUG', true );
    define( 'WP_DEBUG_LOG', true );

    in the wp-config.php file.

    and then check if the log file:
    wp-content/debug.log

    contains any errors.
