Enotif WooCommerce Order 1.0.0  


This Odoo module receives a notification of new order from a WooCommerce website.
After a few minutes the Odoo website sends a request to the WooCommerce website to get the new order data and then saves it as a new order on the Odoo website.

Installation


Requires Odoo 12, WordPress 4.7 or later, WooCommerce 3.5 or later

1) Unzip the downloaded zip archive on your computer.
It contains three folders:
enotif
enotif_woo
enotif_woo_order

2) Put them into the "addons" folder of your Odoo server.
If you don't know where the "addons" folder is located.
When you start odoo from terminal it displays odoo version and the addons paths:
Example:
odoo: Odoo version 12.0-20190806
2019-09-13 06:48:58,433 52031 INFO ? odoo: addons paths: ['/Users/jason/Library/Application Support/Odoo/addons/12.0', '/Users/jason/Odoo12/lib/python3.7/site-packages/odoo-12.0.post20190806-py3.7.egg/odoo/addons']

Also if you can locate the "openerp-server.conf" file (usually located in /etc/odoo on Linux)
You can find the addons paths in it.
If you cannot find the "openerp-server.conf" file you can generate it with command:
./odoo -s -c openerp-server.conf

3) Re-start Odoo
4) Activate the developer mode in Odoo admin panel -> Settings (screenshot)
5) Update the apps list in Odoo admin panel -> Apps (screenshot)
6) Find the "External Notifications" application and install it. (screenshot)
It will automatically install the "Enotif WooCommerce Order" module.
7) Check if it works. Go to Odoo admin panel -> External Notifications
The Order section should be available if this module is installed. (screenshot)

An example of how to use it

 1) On the WooCommerce website install the Notify Odoo WordPress plugin.
2) Go to WordPress dashboard -> WooCommerce -> Settings -> Advanced -> REST API
And click the Add Key button. (screenshot)
3) Generate a key with read/write permissions. (screenshot)
4) Copy the secret keys and save them in some temporary file on your computer. (screenshot)
5) On the Odoo website go to Odoo admin panel -> External Notifications -> WooCommerce Keys
And specify your WooCommerce URL and the secret keys. (screenshot)
6) On the same page click the "Check Connection" button to save the fields and verify the connection to your WooCommerce website. (screenshot)
If there is a connection error it is possible that your WooCommerce website blocks requests from bots, scripts. You should ask your hosting support about it.
7) On the WooCommerce website go to WordPress dashboard -> Notify Odoo
And specify URL of your Odoo website. (screenshot)
8) Click the "Check Connection" button to verify connection from WooCommerce to Odoo (screenshot)
If there is a connection error and the Odoo server is installed on a local computer check if your Odoo server is accessible to the web.
9) If the connection is good then try to make a new order (buy something as a customer) on the WooComerce website. (screenshot)
10) Wait for two minutes. Then go to Odoo admin panel -> Website -> Orders
And check if your new order has been copied from WooCommerce to Odoo (screenshot)
